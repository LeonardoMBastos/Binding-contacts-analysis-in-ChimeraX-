Project Description

Scientific background, objectives, scope, and computational structure of the DockAnalyzer project.

Project Overview

DockAnalyzer is a modular Python toolkit developed to support the identification, classification, scoring, reporting, and visualization of protein–ligand interactions obtained from molecular docking studies.

The project combines docking-pose preparation with an integrated interaction-analysis workflow designed for use with UCSF ChimeraX v1.12 and compatible Python environments.

Main purpose: provide a reproducible workflow for transforming molecular docking outputs into structured and interpretable interaction data.

Abstract

Molecular docking commonly generates multiple ligand poses and predicted binding affinities. However, docking scores alone may not fully describe the molecular interactions responsible for ligand recognition and stabilization within a binding site. DockAnalyzer was designed to complement docking results by evaluating the geometric, chemical, and structural characteristics of protein–ligand contacts.

Main Objectives

  • Separate molecular docking outputs into individual ligand poses.
  • Identify protein–ligand contacts and interaction families.
  • Classify interactions using geometric and chemical criteria.
  • Calculate interaction, residue, and pose-level scores.
  • Compare and rank multiple docking poses.
  • Generate structured tables, reports, statistics, and visual representations.
  • Support reproducible analyses inside and outside UCSF ChimeraX.

Supported Analyses

The modular architecture is intended to support several protein–ligand interaction families, including:

  • General atomic contacts
  • Hydrogen bonds
  • Hydrophobic interactions
  • π–π interactions
  • Cation–π interactions
  • Anion–π interactions
  • Amide–π interactions
  • Salt bridges

Analysis Workflow

1 Prepare Files Prepare receptor, ligand, and molecular docking output files.
2 Split Poses Separate the docking output into individual ligand poses.
3 Analyze Interactions Detect and classify protein–ligand molecular contacts.
4 Score Poses Calculate interaction, residue, and pose-level scores.
5 Generate Results Export reports, tables, statistics, and visualization resources.

Software Architecture

DockAnalyzer is organized as a collection of specialized Python modules. Each module is responsible for a specific stage of the analysis, such as geometry, contact detection, interaction classification, scoring, reporting, export, and visualization.

This modular structure allows individual components to be tested, updated, and reused while preserving an integrated analysis workflow.
