Package Overview

The DockAnalyzer package contains the Python modules required to identify, classify, score, report, and visualize protein–ligand interactions from molecular docking poses.

Keep all downloaded modules together in the extracted DockAnalyzer directory so that internal imports and integrations remain available during execution.

Minimum Requirements

Install or prepare the following components before running the toolkit:

UCSF ChimeraX

UCSF ChimeraX 1.11 or later is recommended. DockAnalyzer accesses molecular structures and session objects through the ChimeraX Python environment.

Python

Python 3.10 or later is recommended for support scripts executed outside ChimeraX. A separate Python installation is not normally required when DockAnalyzer is executed inside ChimeraX.

Operating System

A 64-bit Windows, macOS, or Linux system supported by the installed UCSF ChimeraX release.

Input Files

A prepared receptor structure and one or more individual ligand poses in formats supported by UCSF ChimeraX.

Storage and Permissions

Sufficient local storage and permission to read the input structures and write reports, tables, images, and other analysis outputs.

ZIP Extraction

A standard archive utility capable of extracting .zip files while preserving the internal directory structure.

Installation

1 Download Download DockAnalyzerToolKit_v0.2.9-dev.zip using the button above.
2 Extract Extract the ZIP archive to a local directory and preserve the original file structure.
3 Open ChimeraX and Run Open UCSF ChimeraX, load the receptor and ligand poses, and run analyze.py directly from the extracted DockAnalyzer directory.
