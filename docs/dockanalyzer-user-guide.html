DockAnalyzer — User Guide

Follow the essential steps to run DockAnalyzer in UCSF ChimeraX and understand the files generated by the analysis.

Running DockAnalyzer

Complete the following steps to prepare and run a DockAnalyzer analysis:

1

Download and Extract

Download the DockAnalyzer package and extract the ZIP archive while preserving its original directory structure.

2

Open UCSF ChimeraX

Start UCSF ChimeraX before loading the structures or running the analysis script.

3

Open the Receptor

Open the prepared receptor structure in the ChimeraX session.

4

Open All Ligand Poses

Open every individual ligand pose in the same ChimeraX session as the receptor.

5

Check the Loaded Models

Confirm that the receptor and all ligand poses are correctly displayed and available as separate models.

6

Run analyze.py

Run analyze.py directly from the extracted DockAnalyzer directory using the ChimeraX Python environment.

7

Confirm the Output Directory

Select or confirm the directory where the analysis results will be written, if requested by the final DockAnalyzer interface.

Important: the receptor and all ligand poses must be opened in the same ChimeraX session. Each ligand pose should be provided as an individual structure file.

When a docking output contains multiple poses in a single .pdbqt file, use the Splitting Poses Code before running DockAnalyzer.

Generated Results

Depending on the selected analysis and export settings, DockAnalyzer may generate the following result types:

Result Content Format
Interaction tables Detected contacts and interaction classifications. .csv, .tsv, .xlsx
Analysis report Pose summaries, residues, hotspots, scores, and interpretation. .html, .md, .txt
Structured results Complete machine-readable analysis data. .json
Pose ranking Comparative scores and ranking of the analyzed poses. Included in reports and tables
Residue summary Interactions and scores grouped by protein residue. .csv, .xlsx, report
Interaction statistics Counts, distributions, strengths, and geometric measurements. .csv, .json, report
Visual outputs Interaction representations and molecular snapshots. .png
Analysis metadata Input files, settings, software versions, and execution information. .json, .txt

Output note: the final set of generated files and supported formats should be confirmed after validation of the completed analyze.py workflow.
