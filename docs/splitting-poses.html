Splitting Poses Code

A Python tool for separating molecular docking output files into individual ligand poses for independent analysis.

Tool Overview

The Splitting Poses Code is designed to process molecular docking output files containing multiple predicted ligand conformations and separate them into individual structure files.

Each generated file contains a single docking pose, allowing the predicted conformations to be independently inspected, organized, visualized, and analyzed with DockAnalyzer or other molecular-analysis tools.

Main purpose: transform a docking output containing multiple ligand models into separate files containing one pose each.

Why Split Docking Poses?

Molecular docking programs commonly store several predicted ligand conformations in a single output file. Although this format is useful for preserving the complete docking result, individual pose files may be required for:

  • Independent structural inspection
  • Protein–ligand interaction analysis
  • Pose-specific scoring
  • Visualization in UCSF ChimeraX
  • Comparison between docking conformations
  • Organization of multipose analyses
  • Generation of individual reports and images

Main Functions

  • Read molecular docking output files containing multiple models or poses.
  • Identify the beginning and end of each docking pose.
  • Preserve the molecular coordinates and structural information associated with each pose.
  • Generate one output file for each detected pose.
  • Apply sequential and consistent file names.
  • Prepare pose files for downstream analysis with DockAnalyzer.

Input and Output

Input

The input is a molecular docking output file containing multiple ligand poses. The exact supported format depends on the version of the splitting script.

Example input: docking_output.pdbqt

Output

The script creates a separate file for each pose detected in the original docking output.

Example output files:
  • pose_01.pdbqt
  • pose_02.pdbqt
  • pose_03.pdbqt

Processing Workflow

1 Select Input Choose the molecular docking output file containing multiple ligand poses.
2 Run the Script Execute the Python script using the selected docking file as input.
3 Identify Poses The script detects and separates the individual docking models.
4 Save Files Each pose is saved as an independent molecular structure file.
5 Analyze Poses The generated files can be processed with DockAnalyzer.

Requirements

  • A compatible Python installation
  • A supported docking output format
  • Read permission for the input file
  • Write permission for the output directory

Additional installation and usage instructions should be consulted in the GitHub repository before execution.

Usage Notice

The Splitting Poses Code should be used with molecular docking files that follow the expected structural format. Always preserve a copy of the original docking output before processing it.

The generated pose files should be visually inspected and validated before being included in downstream analyses.
